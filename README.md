### 🧪 Featured Projects

| Project | Description |
|---|---|
| 🦠 **[bacterial-resistance-analyzer](https://github.com/vishveshyatheeswaran-oss/bacterial-resistance-analyzer)** | CLI tool that parses FASTA bacterial genomes and screens sequences against a reference database to detect AMR genes. Includes GC content, nucleotide composition, and mutation detection with full pytest coverage. |
| 🧬 **[tb-amr-predictor](https://github.com/vishveshyatheeswaran-oss/tb-amr-predictor)** | End-to-end ML pipeline predicting isoniazid resistance in *M. tuberculosis* from real WGS data (CRyPTIC Consortium, 300 isolates). Achieved **97.3% sensitivity, 100% specificity, ROC-AUC 0.983**, with model interpretability validated against known clinical resistance mutations (katG S315T, inhA promoter). |
| 📄 **Bachelor Thesis — *H. influenzae* Resistance & Outbreak Analysis** | Investigated resistance patterns and nosocomial outbreak clustering across 414 isolates from Brabant and Zeeland using cgMLST and WGS data. |
